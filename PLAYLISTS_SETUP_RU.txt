EGROV BeatStore — модуль плейлистов

Что добавлено:
- публичный блок «Плейлисты» перед каталогом битов;
- карточки плейлистов с названием, жанром, обложкой и числом битов;
- поиск, фильтр по жанру и сортировка плейлистов;
- просмотр состава плейлиста и прослушивание демо по очереди;
- вкладка «Плейлисты» в админ-панели;
- создание плейлистов, загрузка обложки и выбор битов из существующего каталога;
- удаление плейлистов из админ-панели.

ВАЖНО: перед публикацией примените миграцию к Cloudflare D1.
Откройте Cloudflare Dashboard → Workers & Pages → D1 → база данных сайта → Console.
Выполните SQL из файла egrov_playlists_migration.sql.

После этого загрузите файлы проекта в GitHub и дождитесь нового деплоя Cloudflare Pages.
Если SQL не применить, сайт не сможет загрузить плейлисты и админ-панель не сможет их создавать.
