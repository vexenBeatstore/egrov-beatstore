### Задача 1. Исправить ошибку входа
- Проверь текущую реализацию регистрации и авторизации.
- Найди настоящую причину ошибки входа по логам backend, ответам API и консоли браузера.
- Исправь проблему, не отключая авторизацию и не добавляя обходных путей.
- Проверь регистрацию, вход и выход из аккаунта.
- Не подключай Resend и не требуй подтверждения email на текущем этапе.

### Задача 2. Импортировать биты из SQLite
Я предоставлю файл `vexen_store(1).db` — базу Telegram-бота.

- Используй её только как источник для импорта данных.
- Сохрани отдельную базу сайта и существующую архитектуру проекта.
- Сначала проверь текущую схему сайта и сделай резервную копию перед миграциями.
- Импортируй записи из таблицы `beats`: id, name, genre, bpm, description, price, key, а также цены MP3, WAV и stems, если эти поля поддерживаются каталогом сайта.
- Сопоставь поля с существующей схемой. Не создавай дубликаты при повторном импорте.
- Сохрани цены, BPM, названия и жанры без потери данных.
- Не импортируй Telegram-заказы и Telegram user ID в систему заказов сайта.
- Не удаляй и не изменяй исходную базу.
- Не выдавай Telegram file ID за URL аудиофайла. Отдельно проверь, какие аудио и обложки необходимо загрузить в файловое хранилище сайта.
- После импорта проверь количество записей, отображение каталога, фильтры, сортировку и карточки битов.

### Задача 3. Упростить оформление заказа
- Разреши оформить заказ без обязательной регистрации.
- Добавь поля Telegram username и email.
- Разреши указать хотя бы один способ связи; оба поля необязательны по отдельности, но хотя бы одно должно быть заполнено.
- Проверь данные на сервере.
- Сохраняй контакты в записи заказа вместе с выбранным битом, лицензией, ценой и датой.
- Сохрани текущую логику корзины.
- Не добавляй автоматическую оплату. Заказ должен создаваться с корректным статусом, а способ оплаты и дальнейшие действия должны соответствовать существующей логике магазина.
