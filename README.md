# EGROV BeatStore — запуск без командной строки

Сайт оформлен в чёрном и кислотно-зелёном цветах логотипа EGROV. Файлы проекта можно загрузить через браузер в GitHub и подключить к Cloudflare Pages.

## Важно
- Не загружайте банковские реквизиты, токены бота или другие секреты в GitHub.
- Для рабочей версии настройте в Cloudflare D1 базу, выполните SQL из `schema.sql` через консоль D1 в панели Cloudflare и укажите Database ID в настройках проекта.
- Создайте R2 bucket и привяжите его к проекту как `AUDIO`.
- Установите секреты и переменные окружения, перечисленные ниже, в Cloudflare Dashboard.
- Telegram Login Widget требует привязки домена через @BotFather `/setdomain`.

## Публикация через браузер
1. Откройте GitHub и создайте новый репозиторий `egrov-beatstore-site`.
2. Нажмите **Add file → Upload files**, загрузите содержимое этой папки (не сам ZIP) и нажмите **Commit changes**.
3. В Cloudflare Dashboard откройте **Workers & Pages → Create → Pages → Connect to Git** и выберите репозиторий.
4. Для проекта без сборщика укажите build command пустым, а build output directory — `public`. Если проект создаётся как Pages Functions, убедитесь, что папка `functions` находится в корне репозитория.
5. В Cloudflare D1 создайте отдельную базу, откройте её Console и вставьте содержимое `schema.sql`. Затем замените `REPLACE_WITH_D1_DATABASE_ID` в `wrangler.toml` на Database ID базы.
6. Создайте R2 bucket `egrov-beatstore-audio` или измените имя в `wrangler.toml`, чтобы оно совпадало с созданным bucket.
7. В настройках проекта задайте переменные/секреты из раздела **Environment variables** ниже и выполните повторное развёртывание.

## Переменные и секреты
Сверьтесь с обращениями `env.` в `functions/api/[[path]].js`. Обычно нужны: `ADMIN_TELEGRAM_ID`, `BOT_TOKEN` (токен бота), `TELEGRAM_BOT_USERNAME` (username этого же бота), `BANK_RECIPIENT` и `BANK_DETAILS`. Добавляйте секреты через Cloudflare Dashboard, а не в исходный код.

## Локальные настройки
Файл `.dev.vars.example` — пример локальных переменных. Не публикуйте реальный `.dev.vars`.

## Безопасность и платежи
Оплата подтверждается администратором вручную. Не выдавайте файлы только на основании слов покупателя — сверяйте поступление денег. Перед реальным запуском проверьте Telegram-авторизацию, лимиты загрузки, CORS и доступ к R2.


## Обновление интерфейса EGROV BeatStore

В этой сборке:
- ADMIN находится в верхней панели;
- кастомный демо-плеер: воспроизведение/пауза, перемотка, время и громкость; одновременно играет только одно демо;
- в админке доступны только загрузки обложки и демо;
- Telegram username обязателен при заказе;
- экран оплаты показывает реквизиты, номер заказа и готовый комментарий (Telegram + код заказа + лицензия);
- полные файлы не выдаются автоматически, доставка вручную через Telegram;
- лицензия считается доступной только при цене больше нуля.

### Публикация
1. Сделай резервную копию текущего репозитория.
2. Замени содержимое репозитория файлами из этой папки, сохранив `.dev.vars` только локально и не загружая секреты в Git.
3. Проверь переменные Cloudflare Pages и привязку D1/Storage.
4. Сделай commit и push в ту ветку, из которой собирается Cloudflare Pages.
5. После публикации обнови сайт через Ctrl+Shift+R.

Перед первой реальной продажей проверь тестовый заказ и вручную сверь реквизиты и Telegram администратора.

После загрузки изменений в репозиторий дождись завершения Cloudflare Pages deployment и обнови сайт с очисткой кэша (Ctrl+Shift+R).

## Важное про регистрацию через Telegram и Google

Текущая Telegram-авторизация в проекте предназначена только для администратора и не создаёт пользовательские аккаунты. Не используйте её как регистрацию покупателей без отдельной серверной реализации. Для полноценной регистрации покупателей нужно добавить таблицу пользователей, отдельные пользовательские сессии и обработчики входа. Telegram Login Widget требует публичный username бота и привязку домена через `@BotFather` (`/setdomain`). Google-вход требует OAuth Client ID и Client Secret, созданные в Google Cloud Console, а также точный redirect URI для домена сайта. Эти секреты нужно хранить в настройках Cloudflare, не в GitHub.

## Автовыдача WAV / STEMS (обновление EGROV BeatStore)

- В админке при добавлении бита можно загрузить полный MP3, мастер WAV и ZIP-архив STEMS. Если цена соответствующей лицензии больше 0 ₽, файл для этой лицензии обязателен.
- Мастер-файлы хранятся в приватной логике API в папке `masters/` того же Supabase Storage bucket `egrov`; публичный маршрут медиа не отдаёт содержимое `masters/`.
- Ограничение загрузки каждого файла в приложении — 50 МБ. Проверь, что лимит файла в Supabase Storage для bucket `egrov` не ниже этого значения.
- После ручного нажатия администратором «Подтвердить оплату» заказ автоматически переходит в статус выдачи. Покупатель открывает «Мой заказ» на устройстве, где сохранён ключ доступа, и получает защищённые ссылки на файлы, входящие в оплаченные лицензии.
- Лицензия не предлагается к покупке, если для неё не прикреплён мастер-файл.
- Публичный блок «Услуги» скрыт, если нет активных услуг; появляется автоматически, когда в админке есть хотя бы одна активная услуга.


## Автоматическая выдача купленных файлов в Telegram

Для заказов со способом получения «Telegram» бот отправляет прикреплённые файлы лицензий после нажатия администратором «Подтвердить оплату». Покупатель должен заранее привязать Telegram к заказу по персональной ссылке на странице оформления и нажать START в боте. Username Telegram должен совпадать с указанным в заказе.

### Переменные Cloudflare

Оставь существующие переменные и D1 binding без изменений. Убедись, что заданы:

- `BOT_TOKEN` (или `TELEGRAM_BOT_TOKEN`) — токен именно бота магазина;
- `TELEGRAM_BOT_USERNAME` — username этого бота без `@` (необязательно, если API может получить имя через токен);
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из латинских букв, цифр, `_` и `-`, например длинная случайная комбинация;
- уже используемые `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `SESSION_SECRET`, `ADMIN_TELEGRAM_ID` и D1 binding должны остаться на месте.

### Настройка Telegram webhook

После деплоя зарегистрируй webhook через Telegram Bot API. В адресе ниже замени `BOT_TOKEN` на токен бота и `WEBHOOK_SECRET` на точно такое же значение, которое сохранил в Cloudflare в `TELEGRAM_WEBHOOK_SECRET` (не публикуй получившийся адрес):

`https://api.telegram.org/botBOT_TOKEN/setWebhook?url=https%3A%2F%2Fegrov-beatstore.pages.dev%2Fapi%2Ftelegram%2Fwebhook&secret_token=WEBHOOK_SECRET`

Открой собранный адрес в браузере. Telegram должен вернуть JSON с `"ok":true`. Если для сайта используется другой домен, замени `egrov-beatstore.pages.dev` на актуальный домен.

### Проверка выдачи

1. Создай тестовый заказ, выбрав получение через Telegram и указав username аккаунта-покупателя.
2. Нажми ссылку привязки Telegram на странице заказа и нажми START в боте именно с этого аккаунта.
3. Убедись, что бот ответил, что Telegram привязан к заказу.
4. После тестового платежа нажми в админ-панели «Подтвердить оплату». Бот должен отправить каждый файл из заказа отдельным документом.

Если покупатель не привязал чат, кнопка вернёт понятную ошибку и заказ не будет отмечен выданным. Если файл не прикреплён или Telegram отклонит отправку, API покажет ошибку вместо ложного сообщения об успешной выдаче. Файлы больше лимита Telegram Bot API могут не отправиться.

### Регистрация покупателей и вход

- В окне аккаунта покупатель может войти по логину/паролю, через Telegram Login Widget или нажать «Нет аккаунта? Зарегистрироваться».
- Кнопка регистрации открывает бота с командой `/start register`. Бот создаёт логин и случайный пароль и отправляет их в личный чат. Пользователь должен нажать START и не блокировать бота.
- Убедись, что `BOT_TOKEN` и `TELEGRAM_BOT_USERNAME` относятся к одному боту, а webhook настроен по инструкции выше. Для обновлённой базы D1 таблица `customer_accounts` создаётся автоматически; её также можно добавить через `schema.sql`.
- Для выдачи купленных файлов через Telegram покупатель при оформлении заказа выбирает Telegram, указывает свой `@username` и открывает ссылку привязки бота из результата заказа. После нажатия START бот привяжет чат, а администратор после проверки оплаты нажимает «Подтвердить оплату» — файлы отправятся в этот чат.
- Для входа через Telegram Login Widget домен сайта должен быть настроен у бота через `@BotFather` → `/setdomain`.
